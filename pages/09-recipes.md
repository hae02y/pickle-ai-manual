# 09. 실전 요청 예시

아래 문장은 그대로 복사해 쓰기보다 날짜, 장소, 예산, 제공할 정보를 자기 상황에 맞게 바꾸세요. 실제로 사용하지 않은 기능의 성공을 보장하는 예시는 아닙니다. Pickle이 처리할 수 있다고 안내한 웹 작업·전화·기억·예약 작업을 바탕으로 만든 **권장 요청 형식**입니다. [작업 위임 안내](https://www.pickle.com/help/tasks/delegate)

## 제안 카드에서 시작하기

![피클의 제안 카드가 채팅으로 옮겨진 예시 화면](https://www.pickle.com/help-center/screens/tasks-explore-suggestions.webp)

*이미지 출처: [Pickle 공식 도움말 ― 둘러보기의 제안 카드 쓰기](https://www.pickle.com/help/tasks/explore-suggestions), 2026년 11월 2일 확인. 제안 내용은 사용자와 시점에 따라 달라집니다.*

무엇을 부탁할지 떠오르지 않으면 아래쪽 **둘러보기** 탭의 제안 카드를 살펴보세요. 카드를 열어 내용을 읽고 **시작하기**를 누르면 그 문장이 기본 채팅으로 보내집니다. 보내기 전에 이 장의 예시처럼 날짜·예산·완료 조건을 덧붙여도 좋습니다. 제안 카드는 바로 일을 맡기는 출발점이므로, 예약과 결제는 뒤이어 나오는 조건 카드를 다시 확인하세요. [둘러보기 도움말](https://www.pickle.com/help/tasks/explore-suggestions)

## 1. 후보만 찾기

> “토요일 오후 6시쯤 2명이 갈 식당 후보 세 곳을 찾아줘. 1인당 예산은 5만 원 이내야. 위치, 가격대, 예약 가능 여부와 취소 조건을 표로 비교해 줘. 연락이나 예약 확정은 하지 마.”

첫 요청으로 적합합니다. 정보를 비교한 뒤 사람이 다음 행동을 정할 수 있습니다.

## 2. 전화로 가능 여부만 확인하기

> “이 식당에 토요일 오후 6시 2명 자리가 있는지 문의해 줘. 내 이름과 연락처가 필요한지 먼저 알려 줘. 자리가 있어도 예약 확정이나 예약금 결제는 하지 마.”

전화는 상대방에게 사용자 대신 말하는 행동입니다. 전달할 개인정보와 약속할 수 있는 범위를 먼저 정하세요. Pickle은 전화 기록을 왼쪽 메뉴의 **추가 대화**에서 볼 수 있다고 안내합니다. 통화 종료, 응답 없음, 연결 실패 같은 상태도 구분해 볼 수 있습니다. [추가 대화 보기](https://www.pickle.com/help/chat/other-chats)

## 3. 예약을 요청하기

> “후보 중 A 식당의 토요일 오후 6시 2명 자리를 예약해 줘. 예약금이 없고 취소 수수료가 없는 조건일 때만 진행해 줘. 조건이 다르면 승인 전에 다시 알려 줘. 완료 뒤 예약 번호와 확인 화면을 보여 줘.”

조건이 바뀌면 승인 카드 내용을 다시 확인하세요. 결제와 취소 수수료가 있다면 금액과 마감 시점을 읽어야 합니다. [개인정보·보안 안내](https://www.pickle.com/privacy)

## 4. 정기 요약 만들기

> “매주 월요일 오전에 이번 주 일정에서 내가 직접 결정해야 할 일만 요약해 줘. 다른 사람에게 메시지를 보내거나 일정을 바꾸지는 마.”

사용자가 부탁한 예약 작업은 일일 사용량 한도를 쓸 수 있습니다. 피클 프로필의 **예약한 작업**에서 주기·다음 실행·기록을 확인하고 필요 없으면 일시정지하세요. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)

## 5. 기억 바로잡기

> “내가 채식주의자라는 기억은 잘못됐어. 관련 기억을 보여 주고 수정하거나 삭제할 수 있게 도와줘. 앞으로 식당 추천에는 새 정보를 적용해 줘.”

제품은 피클 프로필의 **함께한 추억**에서 기억을 읽고 수정·삭제할 수 있다고 안내합니다. 중요한 선택에는 현재 요청의 조건을 다시 명시하세요. [공식 소개](https://www.pickle.com/help/start/what-is-pickle)

## 6. 진행 중인 작업의 조건 바꾸기

> “진행 중인 식당 예약은 6시가 아니라 7시로 바꿔 줘. 이미 6시 예약이 확정됐다면 새 예약을 만들지 말고 먼저 상태와 취소 조건을 보여 줘.”

공식 도움말은 채팅에서 조건을 바꾸면 진행 중인 작업에 반영할 수 있다고 안내합니다. 그러나 이미 외부에 확정된 단계까지 자동으로 되돌아가는 것은 아니므로, 예약 내역을 먼저 대조하세요. [진행 중인 일 확인하고 취소하기](https://www.pickle.com/help/tasks/check-and-cancel)

## 7. 작업을 멈추고 상태 확인하기

> “이 주문 작업을 중단해 줘. 결제와 주문이 이미 접수됐는지, 아직 남은 단계가 무엇인지 구분해서 알려 줘. 확인 전에는 다시 결제하지 마.”

작업 카드에서 취소한 뒤에도 외부 사이트에 이미 접수된 결과는 남을 수 있습니다. 주문 내역과 카드 사용 내역을 확인한 다음 재시도 또는 취소를 정하세요. [작업 취소](https://www.pickle.com/help/tasks/check-and-cancel), [결제 후 확인](https://www.pickle.com/help/tasks/confirm-before-payment)

## 요청을 만드는 공식

**목표 + 조건 + 결과 형식 + 금지할 행동 + 승인 시점 + 완료 증거**를 한 문장 또는 짧은 목록으로 적으세요. 모든 요청에 여섯 항목이 필요한 것은 아닙니다. 돈이나 다른 사람과의 약속이 걸리면 마지막 세 항목이 특히 중요합니다.

| 단계 | 독자가 채울 한 문장 |
| --- | --- |
| 시작 | “무엇을 언제까지 해 줘.” |
| 경계 | “이 금액·조건을 넘으면 먼저 물어봐.” |
| 확인 | “끝나면 확인 번호와 외부 기록을 보여 줘.” |

예를 들어 “식당을 예약해 줘”보다 인원, 날짜, 비용 조건, 취소 가능 여부를 함께 쓰면 카드에서 무엇을 승인해야 하는지 분명해집니다. 작업이 끝났다는 메시지만으로 완료로 기록하지 말고 예약처의 확인 메시지까지 대조하세요.
