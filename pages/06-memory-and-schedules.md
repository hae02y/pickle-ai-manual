# 06. 기억과 예약 작업

Pickle은 대화에서 배운 내용을 기억하고, 사용자가 피클 프로필의 **함께한 추억**에서 기억을 읽고 수정·삭제할 수 있다고 안내합니다. 기억은 다음 요청을 더 잘 이해하는 자료이지만, 예전 취향이 새 행동에 대한 무제한 승인이 되지는 않습니다. [공식 소개](https://www.pickle.com/help/start/what-is-pickle)

## 기억을 다루는 방법

| 상황 | 할 일 |
| --- | --- |
| 기억이 맞음 | 오래 유지해도 좋은 선호인지 확인 |
| 기억이 틀림 | 함께한 추억에서 수정하거나 삭제 |
| 기억이 민감함 | 꼭 필요한지 판단하고 보관 여부 재검토 |
| 기억이 오래됨 | 현재도 유효한지 다시 확인 |

예를 들어 “창가 자리를 좋아한다”는 기억은 식당 후보를 추천할 때 도움을 줍니다. 그렇다고 취소 수수료가 있는 예약을 확정할 권한까지 생기는 것은 아닙니다. 중요한 행동은 해당 작업의 카드와 조건으로 확인하세요.

### 기억을 점검하는 순서

화면 위쪽의 피클 모습이나 이름을 눌러 프로필을 연 뒤 **함께한 추억**을 확인하세요. 여기에서 오래된 선호, 잘못 받아들인 사실, 남겨 둘 필요가 없는 민감한 정보를 찾아 고치거나 삭제합니다. 계정을 끊어도 이미 기억에 들어간 정보는 남을 수 있으므로, 연결 해제와 기억 정리를 각각 확인해야 합니다. [화면 구성](https://www.pickle.com/help/start/app-layout), [연결 해제 도움말](https://www.pickle.com/help/connect/disconnect)

## 예약 작업 관리

![피클 프로필의 한 일·예약한 작업·함께한 추억 탭](https://www.pickle.com/help-center/screens/tasks-check-and-cancel.webp)

*이미지 출처: [Pickle 공식 도움말 ― 진행 중인 일 확인하고 취소하기](https://www.pickle.com/help/tasks/check-and-cancel), 2026년 11월 2일 확인. 그림은 프로필의 ‘한 일’ 탭 예시이며, 위쪽 탭에서 예약한 작업과 함께한 추억으로 이동합니다. [화면 구성 도움말](https://www.pickle.com/help/start/app-layout) 참고.*

공식 도움말에 따르면 Pickle은 한 번 또는 매일·매주·매월 반복되는 예약 작업을 수행할 수 있습니다. 기본 채팅에서 “매주 월요일 아침에 이번 주 일정을 요약해 줘”처럼 요청할 수 있습니다. 화면 위쪽의 피클 모습이나 이름을 눌러 프로필의 **예약한 작업**으로 들어가면 일회성·반복·일시 중지된 작업이 나뉘어 보입니다. 각 작업에는 내용, 주기, 다음 실행까지 남은 시간이 표시됩니다. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)

| 관리 항목 | 확인 질문 |
| --- | --- |
| 실행 주기 | 한 번이면 충분한 일을 반복하고 있지 않은가? |
| 읽는 정보 | 매번 어떤 계정·자료를 읽는가? |
| 결과 전달 | 누구에게 어떤 내용이 보이는가? |
| 사용량 | 반복 실행이 하루 한도에 얼마나 영향을 주는가? |
| 종료 | 언제 멈추거나 삭제할 것인가? |

사용자가 부탁한 예약 작업은 실행할 때 일일 사용량 한도를 쓰고, 오늘 한도에 도달하면 한국 시간 새벽 4시 초기화 전까지 실행을 건너뛸 수 있습니다. 기본 아침 브리핑은 한도를 쓰지 않는다고 안내합니다. 중요한 알림을 이것 하나에만 의존하지 않는 편이 좋습니다. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)

작업을 눌러 상세 화면을 열면 **일시정지**, **수정**, **삭제**, **기록**을 선택할 수 있습니다. 예를 들어 휴가 중에는 주간 업무 요약을 일시정지하고, 복귀 후 다시 시작합니다. 삭제는 더 이상 필요 없는 작업에 쓰고, 지난번에 실제로 실행됐는지는 기록에서 확인하세요. 사용자가 멈추거나 지운 작업은 피클이 임의로 다시 실행하지 않는다고 안내합니다. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)
