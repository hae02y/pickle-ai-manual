# 06. 기억과 예약 작업

Pickle은 대화에서 배운 내용을 기억하고, 사용자가 프로필의 **Bubbles**에서 기억을 읽고 수정·삭제할 수 있다고 안내합니다. 기억은 다음 요청을 더 잘 이해하는 자료이지만, 예전 취향이 새 행동에 대한 무제한 승인이 되지는 않습니다. [공식 소개](https://www.pickle.com/help/start/what-is-pickle)

## 기억을 다루는 방법

| 상황 | 할 일 |
| --- | --- |
| 기억이 맞음 | 오래 유지해도 좋은 선호인지 확인 |
| 기억이 틀림 | Bubbles에서 수정하거나 삭제 |
| 기억이 민감함 | 꼭 필요한지 판단하고 보관 여부 재검토 |
| 기억이 오래됨 | 현재도 유효한지 다시 확인 |

예를 들어 “창가 자리를 좋아한다”는 기억은 식당 후보를 추천할 때 도움을 줍니다. 그렇다고 취소 수수료가 있는 예약을 확정할 권한까지 생기는 것은 아닙니다. 중요한 행동은 해당 작업의 카드와 조건으로 확인하세요.

## 예약 작업 관리

공식 도움말에 따르면 Pickle은 한 번 또는 매일·매주·매월 반복되는 예약 작업을 수행할 수 있습니다. Chat에서 “매주 월요일 아침에 이번 주 일정을 요약해 줘”처럼 요청할 수 있습니다. 프로필의 **Scheduled**에서 일회성·반복·일시중지 작업을 확인하고, 작업별로 일시중지, 수정, 삭제, 실행 기록 확인을 할 수 있다고 안내합니다. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)

| 관리 항목 | 확인 질문 |
| --- | --- |
| 실행 주기 | 한 번이면 충분한 일을 반복하고 있지 않은가? |
| 읽는 정보 | 매번 어떤 계정·자료를 읽는가? |
| 결과 전달 | 누구에게 어떤 내용이 보이는가? |
| 사용량 | 반복 실행이 하루 한도에 얼마나 영향을 주는가? |
| 종료 | 언제 멈추거나 삭제할 것인가? |

회사는 사용자가 일시중지하거나 삭제한 작업을 Pickle이 임의로 다시 실행하지 않는다고 설명합니다. 사용자가 부탁한 예약 작업은 실행할 때 일일 사용량 한도를 쓰고, 오늘 한도에 도달하면 한국 시간 새벽 4시 초기화 전까지 실행을 건너뛸 수 있습니다. 기본 아침 브리핑은 한도를 쓰지 않는다고 안내합니다. 중요한 알림을 이것 하나에만 의존하지 않는 편이 좋습니다. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)
