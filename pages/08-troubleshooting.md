# 08. 오류·중단·복구

AI가 “완료했습니다”라고 말했어도 외부 사이트에서는 실패했을 수 있습니다. 반대로 오류 화면이 떠도 예약·결제가 처리됐을 수 있습니다. [Pickle 약관](https://www.pickle.com/ko/terms-of-service)은 웹사이트 변화, 결제 실패, AI의 실수 때문에 결과를 보장할 수 없다고 밝힙니다.

## 먼저 상태를 구분하세요

![피클 프로필의 작업 진행 목록 화면](https://www.pickle.com/help-center/screens/tasks-check-and-cancel.webp)

*이미지 출처: [Pickle 공식 도움말 ― 진행 중인 일 확인하고 취소하기](https://www.pickle.com/help/tasks/check-and-cancel), 2026년 11월 2일 확인. 이 화면의 진행 상태와 외부 사이트의 확정 결과를 각각 확인하세요.*

| 보이는 상황 | 먼저 확인할 것 | 다음 행동 |
| --- | --- | --- |
| 작업이 계속 진행 중 | 작업 카드와 최근 메시지 | 기다리거나 필요한 추가 정보 제공 |
| 로그인·인증 요청 | 요청한 사이트가 맞는지 | 보안 카드나 사용자 직접 인증 사용 |
| 오류·중단 보고 | 외부 사이트의 예약·주문 내역 | 처리되지 않았을 때만 재시도 |
| 완료 보고 | 예약 번호·확인 메시지·결제 내역 | 조건 대조 후 완료로 기록 |
| 잘못된 결과 | 외부 업체의 취소·수정 경로 | Pickle 작업 중단과 별도로 정정 |

기본 채팅의 작업 카드를 누르면 진행 내역이 열립니다. 화면 위쪽의 피클 모습을 눌러 프로필의 **한 일**을 열면 작업이 날짜별로 모여 있고, **작업 중·대기 중·완료·실패·취소됨** 같은 상태를 볼 수 있습니다. 상태가 ‘완료’라도 예약 번호나 주문 내역은 상대 서비스에서 대조하세요. [진행 중인 일 확인하고 취소하기](https://www.pickle.com/help/tasks/check-and-cancel)

## 중단 요청

“지금 작업을 멈춰 줘. 이미 외부에서 확정된 단계와 남은 단계를 나눠 알려 줘”라고 요청하세요. Pickle 약관은 작업이나 예약 행동을 중단할 수 있지만, 제삼자 서비스에서 이미 끝난 단계는 남는다고 설명합니다. [서비스 약관](https://www.pickle.com/ko/terms-of-service)

앱에서 직접 취소할 때는 **작업 카드 또는 한 일 → 해당 작업 → ⋯ → 작업 취소**를 고르고 확인 창에서 취소를 확정합니다. 공식 도움말에 따르면 취소한 작업을 Pickle이 다른 방법으로 임의 재시작하지 않습니다. 다시 진행하려면 새로 요청해야 합니다. 이미 제출된 예약이나 결제는 상대 서비스에서 별도로 취소·환불해야 할 수 있습니다. [작업 확인·취소 도움말](https://www.pickle.com/help/tasks/check-and-cancel)

## 내가 직접 화면을 이어받아야 할 때

![피클 채팅의 브라우저 열기 카드](https://www.pickle.com/help-center/screens/tasks-take-over-browser.webp)

*이미지 출처: [Pickle 공식 도움말 ― 피클 대신 화면을 직접 조작하기](https://www.pickle.com/help/tasks/take-over-browser), 2026년 11월 2일 확인.*

사이트에서 사람만 할 수 있는 조작이 남으면 Pickle이 채팅에 브라우저 카드를 보낼 수 있습니다. **브라우저 열기**를 눌러 현재 화면을 확인하고 필요한 단계를 직접 처리한 다음 **다 했어요**를 누르면 Pickle이 이어서 진행합니다. 카드가 만료됐다면 새로 열어 달라고 요청합니다. 휴대전화에 저장된 로그인은 Pickle의 별도 브라우저로 자동 전달되지 않습니다. [화면 직접 조작하기](https://www.pickle.com/help/tasks/take-over-browser)

화면을 이어받는 동안 예약 제출이나 결제를 직접 했다면, Pickle에게 재시도시키기 전에 외부 내역에서 이미 처리됐는지 확인하세요. 이는 중복 처리를 피하기 위한 이 매뉴얼의 권장 절차입니다.

## 재시도 전 3단계

1. **외부 상태 조회:** 상대 사이트의 예약·주문·결제 내역을 확인합니다.
2. **중복 위험 점검:** 같은 요청이 다시 실행되면 예약·주문이 두 개 생길 수 있는지 봅니다.
3. **조건 재확인:** 가격·날짜·대상·취소 규칙이 바뀌었다면 새 카드에서 다시 승인합니다.

이 절차는 매뉴얼의 권장 방법입니다. Pickle의 자동 재시도 동작을 설명하는 것은 아닙니다.

결제 화면이 끊겼을 때는 공식 도움말도 **바로 다시 결제하지 않고 먼저 결제 여부를 확인한다**고 안내합니다. 이미 결제됐는지 알 수 없으면 카드 내역, 주문 기록, 확인 번호를 먼저 확인하세요. [결제 전 확인 도움말](https://www.pickle.com/help/tasks/confirm-before-payment)

## 문의 기록 양식

| 항목 | 적을 내용 |
| --- | --- |
| 요청 | 무엇을 언제 맡겼는가 |
| 기대 결과 | 어떤 조건으로 완료돼야 했는가 |
| Pickle 보고 | 어떤 상태와 증빙을 보여 줬는가 |
| 외부 상태 | 업체 사이트·결제 내역에는 무엇이 남았는가 |
| 이미 한 조치 | 중단, 재시도, 업체 문의, 취소 여부 |

지원 문의를 보낼 때는 비밀번호·카드 번호·인증 코드를 넣지 마세요. 필요한 기록만 전달하세요.
