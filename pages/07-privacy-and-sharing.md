# 07. 개인정보와 공유

개인 에이전트가 편리해질수록 대화, 일정, 연락처, 연결 계정에 관한 정보를 더 많이 알게 됩니다. “AI가 비밀번호를 읽지 않는다”는 설명만으로 전체 개인정보 흐름을 이해할 수는 없습니다.

## 누가 무엇을 볼 수 있나요?

| 주체 | 회사가 안내하는 범위 |
| --- | --- |
| Pickle의 AI | 대화, 기억, 연결 계정에서 읽은 정보. 비밀번호·카드 번호·계정 토큰은 AI에 직접 전달하지 않는다고 설명 |
| AI 제공업체 | 답변 생성에 필요한 정보만 처리한다고 설명 |
| Pickle 운영 인력 | 서비스 운영·문제 해결·안전 대응 등을 위해 승인된 인력이 일부 대화·기억을 볼 수 있고 조회 기록이 남는다고 설명 |
| 다른 사람 | 사용자가 공개하거나 공유 설정에서 허용한 범위의 정보 |

위 표는 [Pickle 개인정보 안내](https://www.pickle.com/privacy)의 회사 설명을 요약한 것입니다. 제품의 내부 통제를 독립적으로 검증했다는 뜻은 아닙니다. 연결하기 전에는 개인정보처리방침의 최신 내용을 직접 읽으세요.

## 공유 범위 확인

![피클 앱의 정보 공개 범위 설정 화면](https://www.pickle.com/help-center/screens/privacy-sharing-settings.webp)

*이미지 출처: [Pickle 공식 도움말 ― 정보 공개 범위 설정하기](https://www.pickle.com/help/privacy/sharing-settings), 2026년 11월 2일 확인.*

Pickle의 약관은 친구나 다른 사람의 Pickle과 대화할 수 있으며, 사용자가 고른 공유 설정에 따라 Pickle이 대신 말할 수 있다고 설명합니다. 따라서 친구 기능을 사용할 때는 공유 수준과 사람별 설정, 공유하지 않을 항목을 점검하고 실제 대화를 확인해야 합니다. [서비스 약관](https://www.pickle.com/ko/terms-of-service)

| 공유 전 질문 | 예 |
| --- | --- |
| 누구에게 말하나요? | 친구 한 명, 업체 직원, 불특정 사용자 |
| 무엇을 말하나요? | 일정 가능 시간, 연락처, 개인 취향 |
| 대리 발언인가요? | 상대가 내 입장이나 약속으로 받아들일 내용인지 |
| 나중에 확인할 수 있나요? | 대화·통화 기록 위치 |

## 데이터 관리 습관

기억은 정기적으로 수정·삭제하고, 쓰지 않는 계정 연결을 끊으세요. 채팅에 비밀번호나 카드 번호를 적지 마세요. 계정을 삭제할 때는 앱의 계정 삭제 경로와 [개인정보처리방침](https://www.pickle.com/ko/privacy-policy)의 보관 예외를 먼저 확인하세요. 한국어 약관은 **설정 → 계정 → 계정 삭제하기**를 안내합니다. [한국어 서비스 약관](https://www.pickle.com/ko/terms-of-service)
