# 07. 개인정보와 공유

개인 에이전트는 대화와 일정, 연락처, 연결 계정에서 필요한 내용을 읽습니다. 비밀번호를 모델에 직접 보여 주지 않더라도, 업무를 처리하는 동안 메일 본문이나 약속 내용은 다른 경로로 이동합니다. 따라서 **비밀값 보호**, **작업에 필요한 정보 처리**, **다른 사람에게 하는 말**을 따로 살펴야 합니다. [Pickle 개인정보·보안 설명](https://www.pickle.com/how-your-pickle-protects-your-privacy)

**자료 시점:** 이 장에서 연결한 한국어 약관 페이지는 2026년 11월 24일 확인 때 **12월 8일 시행 예정**으로 표시됐습니다. 현재 계정의 공유·삭제 조건은 앱 화면과 현행 지역 약관을 확인하세요. [18장 업데이트 노트](https://wikidocs.net/498492)

예를 들어 업무 캘린더를 연결했다고 합시다. Pickle이 빈 시간을 찾으려면 일정을 읽을 수 있지만, 친구에게는 “목요일 8시 이후 가능”만 말하도록 범위를 정할 수 있습니다. 식당 예약을 부탁했다면 업체에는 이름이나 연락처가 필요할 수 있습니다. 각각 목적과 상대가 다릅니다.

## 누가 무엇을 볼 수 있나요?

| 주체 | 회사가 안내하는 범위 |
| --- | --- |
| Pickle의 AI | 대화·기억·연결 계정의 응답 내용. 계정 토큰과 Vault의 비밀값은 모델에 직접 건네지 않는다고 설명 |
| AI 제공업체 | 답변 생성에 필요한 정보만 처리한다고 설명 |
| Pickle 운영 인력 | 서비스 운영·문제 해결·안전 대응 등을 위해 승인된 인력이 일부 대화·기억을 볼 수 있고 조회 기록이 남는다고 설명 |
| 다른 사람 | 사용자가 공개하거나 공유 설정에서 허용한 범위의 정보 |

위 표는 [Pickle의 보안 설명](https://www.pickle.com/how-your-pickle-protects-your-privacy)을 요약한 것입니다. 토큰이 격리된 환경에 있어도, 거기에서 가져온 메일 내용은 작업 처리에 사용됩니다. 회사가 설명한 통제의 일부는 아직 외부에서 검증할 수 없다고 회사도 밝힙니다. 연결 전에 최신 개인정보처리방침과 앱의 권한 화면을 읽으세요.

**공개 범위 설정은 다른 사람에게 전하는 말의 범위**를 정합니다. AI 제공사가 답변을 만들기 위해 정보를 처리하는 방식이나 Pickle 운영 인력의 허용된 열람을 이 설정으로 끄는 것은 아닙니다. 이 둘은 [내 정보는 누가 볼 수 있나요?](https://www.pickle.com/help/privacy/who-can-see)에서 따로 확인하세요.

## 공유 범위 확인

![피클 앱의 정보 공개 범위 설정 화면](https://www.pickle.com/help-center/screens/privacy-sharing-settings.webp)

*이미지 출처: [Pickle 공식 도움말 ― 정보 공개 범위 설정하기](https://www.pickle.com/help/privacy/sharing-settings), 2026년 11월 2일 확인.*

친구 기능을 쓸 때는 공유 수준, 사람별 설정, 누구에게도 말하지 않을 항목을 먼저 점검하세요. 상대의 Pickle에게 건넨 말은 상대 사용자에게 전달되는 말로 취급해야 합니다. 이미 전달된 말은 설정을 바꿔도 거둬들일 수 없으므로, 대화 기록도 확인하세요. [Pickle 개인정보·보안 설명](https://www.pickle.com/how-your-pickle-protects-your-privacy)

2026년 11월 2일 확인한 [정보 공개 범위 설정 도움말](https://www.pickle.com/help/privacy/sharing-settings)은 **나의 피클 → 정보 공개 범위 설정**에서 ‘간단한 안부 정도만’과 ‘일상 근황까지’를 고르게 하고, 후자를 기본값으로 설명했습니다. 이후 [누가 내 정보를 볼 수 있나요?](https://www.pickle.com/help/privacy/who-can-see)와 [Pickle 개인정보·보안 설명](https://www.pickle.com/how-your-pickle-protects-your-privacy)은 연락처의 사람별 공유 수준과 ‘모두 공유’ 같은 표현을 사용합니다. 화면 명칭과 기본값은 계정·버전에 따라 확인하고, 예시 답변이 의도한 정보량인지 직접 읽으세요.

| 공유 전 질문 | 예 |
| --- | --- |
| 누구에게 말하나요? | 친구 한 명, 업체 직원, 불특정 사용자 |
| 무엇을 말하나요? | 일정 가능 시간, 연락처, 개인 취향 |
| 대리 발언인가요? | 상대가 내 입장이나 약속으로 받아들일 내용인지 |
| 나중에 확인할 수 있나요? | 대화·통화 기록 위치 |

### 앱별 공개 범위와 예외

| 설정 | 공식 도움말이 안내하는 효과 |
| --- | --- |
| 연결한 앱: 말하지 않음 | 그 앱에서 읽은 내용을 다른 사람에게 말하지 않음. 기본값 |
| 친구의 피클들에게 허용 | 친구의 피클과 대화할 때 해당 앱의 정보를 사용할 수 있음 |
| 누구에게나 허용 | 친구 밖의 상대와 이야기할 때도 해당 앱의 정보를 사용할 수 있음 |
| 사람별 설정 | 특정 친구의 피클에게만 따로 당부할 내용을 적음 |
| 누구에게도 말하지 않는 것 | 사람별 허용보다 먼저 적용할 제외 내용을 직접 적음 |

예를 들어 업무 캘린더를 연결했더라도 다른 사람에게 회의 제목과 참석자를 말할 필요는 없을 수 있습니다. 공식 도움말의 **시간 되는지만 말하기**를 사용하면 시간의 가능 여부만 답하도록 정할 수 있지만, 캘린더 자체를 말하지 않게 해 두었다면 이 설정만으로 정보가 열리지는 않습니다. [정보 공개 범위 설정](https://www.pickle.com/help/privacy/sharing-settings)

| 상황 | 상대에게 필요한 정보 | 보통 필요하지 않은 정보 |
| --- | --- | --- |
| 약속 시간 조율 | 가능한 시간대 | 다른 일정의 제목·참석자 |
| 식당에 자리 문의 | 날짜·시간·인원 | 다른 식당에서의 예약 내역 |
| 친구의 피클과 대화 | 사용자가 허용한 근황 | 연결 계정의 원문 전체 |

이 표는 제품의 자동 필터 규칙이 아니라 **공유 범위를 생각해 보는 예시**입니다. 상대에게 필요한 최소 정보가 무엇인지 먼저 정하고 실제 공유 설정과 대화 기록을 확인하세요.

친구와의 대화가 시작됐다면 왼쪽 메뉴의 **추가 대화**에서 실제로 오간 말을 확인하세요. 공개 범위를 바꾼 뒤에는 설정 화면의 예시 답변을 확인하고, 이후 새 대화에서 적용됐는지도 살핍니다. 과거 대화의 상대방 보유본까지 바뀌는 것은 아닙니다. [추가 대화 보기](https://www.pickle.com/help/chat/other-chats), [Pickle 개인정보·보안 설명](https://www.pickle.com/how-your-pickle-protects-your-privacy)

## 데이터 관리 습관

기억은 정기적으로 고치거나 삭제하고, 쓰지 않는 계정 연결은 끊으세요. 채팅에는 비밀번호·카드 번호·인증 코드를 적지 않습니다. 계정 삭제를 고려한다면 앱에서 제공하는 경로와 실제 적용되는 개인정보처리방침의 보관·삭제 조건을 확인하세요. 2026년 11월 24일 확인한 [한국어 서비스 약관](https://www.pickle.com/ko/terms-of-service)에는 **설정 → 계정 → 계정 삭제하기**가 적혀 있지만, 이 URL에 표시된 문서의 시행일은 12월 8일입니다.

> **기술 분석:** 다른 사용자에게 공유되는 정보, Pickle의 AI 시스템이 작업 처리를 위해 읽는 정보, 연결 서비스로 보내는 정보는 **서로 다른 데이터 흐름**입니다. 공유 설정 하나가 모든 처리 경로를 끊는다고 가정하지 마세요. OAuth 토큰 자체는 enclave 안에 남아도 API 응답 내용은 작업 처리 영역으로 전달될 수 있습니다. [14장](https://wikidocs.net/491193)의 데이터 표와 [16장](https://wikidocs.net/491195)의 위협 모델을 확인하세요.
