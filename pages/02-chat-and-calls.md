# 02. 대화와 음성 통화

Pickle의 채팅과 음성 통화는 같은 대화 흐름으로 이어진다고 회사가 설명합니다. 음성으로 말했어도, 중요한 날짜·금액·사람 이름은 채팅에 남은 내용을 다시 확인하는 습관이 좋습니다. [공식 소개](https://www.pickle.com/help/start/what-is-pickle), [음성 통화 안내](https://www.pickle.com/help/chat/voice-call)

## 채팅으로 요청하기

요청은 네 가지 정보가 있으면 이해하고 검토하기 쉽습니다.

| 요소 | 예 |
| --- | --- |
| 목표 | 토요일 저녁 식당 후보를 찾기 |
| 조건 | 2명, 오후 7시, 1인당 예산 |
| 결과 | 후보 3곳과 가격·취소 조건 비교 |
| 행동 경계 | 예약이나 결제 전에는 나에게 확인 |

“좋은 식당 잡아 줘”처럼 짧게 말해도 Pickle이 추가 질문을 할 수 있습니다. 다만 사용자가 빠뜨린 예산이나 날짜를 AI가 임의로 결정하지 않도록, 중요한 조건은 먼저 말하는 편이 안전합니다. 회사는 선택지가 있을 때 사용자에게 보여 주고, 작업 전에 실행 조건을 담은 카드를 제시한다고 안내합니다. [작업 위임 안내](https://www.pickle.com/help/tasks/delegate)

## 음성으로 말하기

![피클 앱의 음성 통화 화면](https://www.pickle.com/help-center/screens/chat-voice-call.webp)

*이미지 출처: [Pickle 공식 도움말 ― 피클과 통화하기](https://www.pickle.com/help/chat/voice-call), 2026년 11월 2일 확인.*

[공식 통화 도움말](https://www.pickle.com/help/chat/voice-call)에 따르면 Chat 탭에서 입력칸이 비어 있을 때 통화 버튼이 나타납니다. 통화 중에는 스피커, 음소거, 종료 버튼을 사용할 수 있습니다. 통화 화면을 작게 줄여 채팅을 보면서 대화할 수도 있습니다.

음성 통화 내용을 회사는 답변 생성을 위해 서버로 보내고, 말한 내용은 문자로 바뀌어 대화에 남는다고 설명합니다. 따라서 민감한 정보를 말하기 전에 저장·처리 방식을 확인하세요. 통화가 끝나면 날짜, 가격, 예약 여부 같은 핵심 조건을 문자로 다시 적어 달라고 요청하면 확인하기 쉽습니다. [음성 통화 안내](https://www.pickle.com/help/chat/voice-call)

## 요청을 고칠 때

| 상황 | 이렇게 말해 보세요 |
| --- | --- |
| 결과가 너무 넓음 | “서울 전체 말고 강남역에서 도보 15분 이내로 좁혀 줘.” |
| 행동을 멈추고 싶음 | “예약 진행을 멈춰 줘. 이미 확정된 단계가 있는지 먼저 알려 줘.” |
| 잘못 기억함 | “내가 채식주의자라는 기억은 틀렸어. 그 기억을 보여 주고 수정해 줘.” |

대화로 정정하더라도 외부 사이트에서 이미 완료된 예약이나 주문은 별도로 취소해야 할 수 있습니다. [서비스 약관](https://www.pickle.com/ko/terms-of-service)은 완료된 외부 단계를 중단 명령만으로 되돌릴 수 없다고 설명합니다.
