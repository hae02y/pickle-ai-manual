# 01. 시작 전 확인

Pickle을 설치하기 전에 두 가지를 확인하세요. 내 지역과 계정에서 서비스를 쓸 수 있는지, 첫 작업을 어디까지 맡길지입니다.

이용 자격은 문서마다 다르게 안내됩니다. 11월 2일 편집 기록에는 당시 한국어 약관의 만 16세 이상과 만 19세 미만 법정대리인 동의 조건이 남아 있습니다. 다만 그 버전의 고정 사본은 없고 현재 URL은 다른 문서를 보여 줍니다. 11월 17일 확인한 [영어 공식 소개](https://pickle.com/help/start/what-is-pickle)는 **18세 이상**이라고 안내했습니다. 가입 화면에서 자신에게 제시되는 조건을 확인하세요.

**2026년 11월 24일 자료 시점:** 현재 [한국어 약관 URL](https://www.pickle.com/ko/terms-of-service)은 **12월 8일 시행 예정** 문서를 보여 줍니다. 그 내용을 11월 24일의 현행 약관으로 읽어서는 안 됩니다. 문서 차이와 확인 순서는 [18장 업데이트 노트](https://wikidocs.net/498492)에 정리했습니다.

## 첫날 점검표

| 확인할 것 | 왜 필요한가 | 확인 위치 |
| --- | --- | --- |
| 제공 지역·연령 | 서비스 대상에 해당하는지 | 가입 화면·앱 안내와 적용되는 지역 약관 |
| 사용량 한도·요금 | 작업·대화가 언제 제한되는지 | 계정의 플랜·사용량 화면 |
| 처음 맡길 일 | 오류가 나도 쉽게 바로잡을 수 있는지 | 자신의 할 일 목록 |
| 연결할 계정 | 필요한 자료만 열어 주는지 | My Pickle → Connections |
| 결제 수단 | 첫 실습에 정말 필요한지 | Payment methods 또는 결제 카드 |

처음부터 카드와 모든 계정을 연결할 이유는 없습니다. 예를 들어 공개된 정보로 식당 후보 세 곳을 비교해 달라는 요청은 연결 없이 시작할 수 있는 설명용 실습입니다. 실제로 제공되는 검색 범위는 계정과 지역에 따라 확인하세요. 결과를 검토한 뒤 필요한 계정만 연결하는 것이 이 매뉴얼의 **권장 방법**입니다.

첫날에는 작은 요청 하나를 내고, 돌아온 정보의 근거를 직접 확인해 보세요. 이 과정에서 피클이 되묻는 조건과 사용자가 직접 결정해야 하는 조건을 구분할 수 있습니다.

## 무엇을 할 수 있나요?

Pickle은 대화와 음성 통화, 기억, 웹사이트에서의 작업, 전화, 연결 계정 활용을 안내합니다. 작업마다 가능한 범위가 다르고, 웹사이트의 정책이나 결제·로그인 단계 때문에 사람이 이어받아야 할 수도 있습니다. [공식 소개](https://www.pickle.com/help/start/what-is-pickle), [작업 위임 안내](https://www.pickle.com/help/tasks/delegate)

| 첫 요청으로 적합 | 조금 익숙해진 뒤 | 충분히 검토한 뒤 |
| --- | --- | --- |
| 후보 검색·비교·요약 | 일정 조율·예약 문의 | 예약 확정·구매·취소·신청서 제출 |

표의 오른쪽으로 갈수록 다른 사람과의 약속, 금전, 개인정보가 관련됩니다. Pickle이 할 수 있다고 소개하는 기능이라도 사용자가 실제로 어디까지 위임할지는 별도로 정해야 합니다.

## 앱을 시작하는 순서

![피클 앱의 기본 채팅 화면과 아래쪽 탭](https://www.pickle.com/help-center/screens/chat-basic.webp)

*이미지 출처: [Pickle 공식 도움말 ― 화면 구성 알아보기](https://www.pickle.com/help/start/app-layout), 2026년 11월 2일 확인. 실제 화면은 앱 버전에 따라 다를 수 있습니다.*

1. [Pickle 공식 사이트](https://www.pickle.com/)에서 현재 제공하는 앱 다운로드 경로를 확인합니다.
2. 가입 화면과 자신에게 적용되는 지역 약관에서 이용 자격을 확인합니다. 위의 영어 안내와 과거 한국어 약관의 연령 기준은 다릅니다.
3. 계정의 **플랜·사용량 화면**에서 한도와 초기화 시각을 확인합니다. 과거 한국어 안내와 영어 안내의 한도 설명이 달랐으므로 숫자를 외우기보다 현재 계정 화면을 보세요. [10장](https://wikidocs.net/471762)에 차이를 기록했습니다.
4. 첫날에는 외부 행동이나 결제가 없는 요청을 하나 보냅니다.
5. 연결 계정과 결제 수단은 해당 작업에 필요해질 때 추가합니다.

공식 자료에서 확인한 메뉴 이름만 이 매뉴얼에 적었습니다. 앱 버전에 따라 화면 배치가 달라지면 [공식 도움말](https://www.pickle.com/help)을 기준으로 찾으세요.

| 찾을 기능 | 공식 도움말에서 안내하는 위치 |
| --- | --- |
| 대화·음성 통화 | Chat 탭 |
| 연결 계정·사이트 로그인 | My Pickle → Connections |
| 기억 확인·수정 | Pickle 프로필 → Bubbles |
| 예약 작업 | Pickle 프로필 → Scheduled |
| 사용량·플랜 | 현재 계정의 플랜·사용량 화면; 지역·버전에 따라 다름 |

[공식 소개](https://www.pickle.com/help/start/what-is-pickle), [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled), [사용량 도움말](https://www.pickle.com/help/credits/usage-credits)

## 첫 요청 예시

> “이번 금요일 저녁에 2명이 갈 식당 후보를 세 곳 찾아줘. 가격대와 예약 가능 여부를 비교해 줘. 예약 확정이나 결제는 하지 말고 먼저 나에게 보여 줘.”

이 문장은 설명을 위한 예시이며 실제로 예약을 시험한 기록은 아닙니다. 목적, 조건, 결과 형식, 금지한 행동이 들어 있습니다. 처음에는 후보를 검토한 뒤 예약·결제의 품목과 금액 범위를 정하세요. 한 번 허용한 범위에서 피클이 매번 다시 묻지 않을 수 있으므로, 허용 조건을 구체적으로 적어 두는 것이 중요합니다.

답변을 받으면 후보의 가격이나 예약 가능 여부가 **어디에서 확인된 정보인지** 물어보세요. 식당 웹페이지의 안내와 실제 빈자리 정보는 다를 수 있습니다. 첫 요청의 완료 기준은 예약 성공이 아니라, 사용자가 후보와 출처를 읽고 다음 행동을 선택할 수 있는 상태입니다.

## 다음 단계

대화 화면에서 요청을 보내고, Pickle이 무엇을 제안하는지 살펴보세요. 실제 행동을 맡기기 전에는 [03. 작업 위임](https://wikidocs.net/471755)을 읽으세요. 요청문부터 결과 확인까지 한 사례로 따라가려면 [17. 첫 작업 맡기기](https://wikidocs.net/493290)를 이용하세요.

## 기술적으로 읽기

Pickle은 대화, 작업 계획, 웹·전화 실행, 계정 연결, 승인, 결과 확인이 이어지는 **에이전트 시스템**입니다. 사용자의 자연어 목표를 실제 행동으로 바꾸는 AI 모델의 세부 구조는 공개되지 않았습니다. 반면 계정 자격 증명을 처리하는 공개 소스는 확인할 수 있습니다. 두 증거의 차이는 [11장](https://wikidocs.net/491190)에서 설명합니다. 처음 요청은 **목표·금지 행동·완료 증거**를 모두 적어야 나중에 결과를 확인할 수 있습니다.
