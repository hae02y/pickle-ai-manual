# 01. 시작 전 확인

Pickle을 설치하기 전에 “무슨 일을 시킬까?”보다 “내가 이용할 수 있는 서비스인가?”를 먼저 확인하세요. [공식 약관](https://www.pickle.com/terms-of-service)은 미국에 있는 만 18세 이상을 이용 대상으로 적고 있습니다. 한국에서 앱이 보이거나 설치되더라도 약관상 이용 대상과 제공 지역은 별개의 문제입니다.

## 첫날 점검표

| 확인할 것 | 왜 필요한가 | 확인 위치 |
| --- | --- | --- |
| 거주 지역·연령 | 서비스 대상에 해당하는지 | 최신 약관·앱 안내 |
| 구독 요금과 사용 한도 | 작업·대화가 비용에 미치는 영향 | 앱의 요금제 화면 |
| 처음 맡길 일 | 오류가 나도 쉽게 바로잡을 수 있는지 | 자신의 할 일 목록 |
| 연결할 계정 | 필요한 자료만 열어 주는지 | My Pickle → Connections |
| 결제 수단 | 첫 실습에 정말 필요한지 | Payment methods 또는 결제 카드 |

처음부터 카드와 모든 계정을 연결할 이유는 없습니다. 예를 들어 식당 후보를 세 곳 찾는 일은 계정 연결 없이도 시험해 볼 수 있는 낮은 위험의 요청입니다. 결과가 어떻게 제시되는지 살펴본 다음, 필요한 계정만 연결하는 순서가 좋습니다. 이는 이 매뉴얼의 **권장 방법**입니다.

## 무엇을 할 수 있나요?

Pickle은 대화와 음성 통화, 기억, 웹사이트에서의 작업, 전화, 연결 계정 활용을 안내합니다. 작업마다 가능한 범위가 다르고, 웹사이트의 정책이나 결제·로그인 단계 때문에 사람이 이어받아야 할 수도 있습니다. [공식 소개](https://www.pickle.com/help/start/what-is-pickle), [작업 위임 안내](https://www.pickle.com/help/tasks/delegate)

| 첫 요청으로 적합 | 조금 익숙해진 뒤 | 충분히 검토한 뒤 |
| --- | --- | --- |
| 후보 검색·비교·요약 | 일정 조율·예약 문의 | 예약 확정·구매·취소·신청서 제출 |

표의 오른쪽으로 갈수록 다른 사람과의 약속, 금전, 개인정보가 관련됩니다. Pickle이 할 수 있다고 소개하는 기능이라도 사용자가 실제로 어디까지 위임할지는 별도로 정해야 합니다.

## 앱을 시작하는 순서

1. [Pickle 공식 사이트](https://www.pickle.com/)에서 현재 제공하는 앱 다운로드 경로를 확인합니다.
2. 가입 화면과 최신 약관에서 자신이 이용 대상에 해당하는지 확인합니다. 약관은 미국 내 만 18세 이상을 대상으로 명시합니다.
3. 앱의 요금제 화면에서 필요한 플랜과 주간 한도를 확인합니다. 가격은 결제 직전 표시값을 기준으로 판단합니다.
4. 첫날에는 외부 행동이나 결제가 없는 요청을 하나 보냅니다.
5. 연결 계정과 결제 수단은 해당 작업에 필요해질 때 추가합니다.

공식 자료에서 확인한 메뉴 이름만 이 매뉴얼에 적었습니다. 앱 버전에 따라 화면 배치가 달라지면 [공식 도움말](https://www.pickle.com/help)을 기준으로 찾으세요.

| 찾을 기능 | 공식 도움말에서 안내하는 위치 |
| --- | --- |
| 대화·음성 통화 | Chat 탭 |
| 연결 계정·사이트 로그인 | My Pickle → Connections |
| 기억 확인·수정 | Pickle 프로필 → Bubbles |
| 예약 작업 | Pickle 프로필 → Scheduled |
| 요금제 | My Pickle의 플랜 카드 또는 My account → Subscription |

[공식 소개](https://www.pickle.com/help/start/what-is-pickle), [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled), [요금제 도움말](https://www.pickle.com/help/credits/plans)

## 첫 요청 예시

> “이번 금요일 저녁에 2명이 갈 식당 후보를 세 곳 찾아줘. 가격대와 예약 가능 여부를 비교해 줘. 예약 확정이나 결제는 하지 말고 먼저 나에게 보여 줘.”

이 문장에는 목적, 조건, 결과 형식, 금지한 행동이 들어 있습니다. 처음부터 완벽한 지시를 만들 필요는 없지만, **확정과 결제는 별도로 결정한다**는 경계는 분명히 해 두세요.
