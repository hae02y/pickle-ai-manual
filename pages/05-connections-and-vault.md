# 05. 연결 계정과 Vault

Pickle은 Google, Microsoft, Slack, Notion 같은 계정과 휴대전화의 연락처·캘린더 등을 연결할 수 있다고 안내합니다. 연결하면 Pickle이 관련 정보를 읽고 작업에 사용할 수 있습니다. 필요한 계정 하나부터 연결하고, 어떤 자료를 읽을 수 있게 되는지 확인하세요. [공식 소개](https://www.pickle.com/help/start/what-is-pickle), [서비스 약관](https://www.pickle.com/ko/terms-of-service)

## 연결 전에 정할 것

![피클 앱의 앱 및 서비스 연결 목록](https://www.pickle.com/help-center/screens/connect-add-connection.webp)

*이미지 출처: [Pickle 공식 도움말 ― 앱과 서비스 연결하기](https://www.pickle.com/help/connect/add-connection), 2026년 11월 2일 확인. 화면은 연결할 수 있는 서비스의 예시입니다.*

| 질문 | 기록할 답 |
| --- | --- |
| 무슨 일을 하려고 연결하나요? | 예: 내 일정에서 빈 시간 찾기 |
| 어떤 계정이 필요한가요? | 개인 캘린더 하나인지, 업무 계정인지 |
| 누구의 정보가 포함되나요? | 내 정보 외에 동료·고객 정보가 있는지 |
| 언제 연결을 끊을까요? | 시험 후 또는 작업 종료 후 |

업무 계정이나 다른 사람의 정보가 들어 있는 계정은 자신에게 연결 권한이 있는지 먼저 확인하세요. Pickle의 약관도 연결할 권리가 있는 계정만 연결하도록 요구합니다. [서비스 약관](https://www.pickle.com/ko/terms-of-service)

### 앱에서 계정 연결하기

공식 도움말은 **나의 피클 → (피클 이름)에 연결된 앱 및 서비스 → 연결 추가**의 순서를 안내합니다. 목록에서 서비스를 고른 뒤 해당 서비스의 로그인과 권한 요청을 확인합니다. 작업 도중 연결이 필요해지면 채팅에 연결 카드가 나타날 수도 있습니다. 휴대전화의 연락처나 일정은 별도의 접근 허용 창이 뜰 수 있습니다. [앱과 서비스 연결하기](https://www.pickle.com/help/connect/add-connection)

| 화면에서 볼 것 | 확인할 질문 |
| --- | --- |
| 연결 대상 | 내가 쓰려는 개인 계정인가, 업무 계정인가? |
| 요청 권한 | 읽기만 필요한데 쓰기 권한까지 요구하는가? |
| 포함된 사람 | 고객·동료의 정보가 함께 들어 있는가? |
| 연결 후 사용 | 이 작업이 끝나면 계속 연결해 둘 이유가 있는가? |

공식 도움말에 따르면 새로 연결한 계정은 Pickle이 사용자를 이해하고 할 일을 찾는 데 폭넓게 읽을 수 있습니다. 읽은 내용이 대화·기억·작업 기록에 남을 수도 있습니다. 연결 버튼을 누르기 전에 이 범위를 염두에 두세요. [앱과 서비스 연결하기](https://www.pickle.com/help/connect/add-connection)

## 사이트 로그인 저장

[공식 로그인 도움말](https://www.pickle.com/help/connect/save-login)에 따르면 Pickle이 로그인해야 할 때 채팅에 **(사이트) 로그인** 카드가 나타납니다. 아이디와 비밀번호를 카드에 입력하고 **금고에 저장**을 누릅니다. 저장한 로그인은 **나의 피클 → (피클 이름)에 연결된 앱 및 서비스 → 해당 사이트**에서 관리할 수 있습니다. 비밀번호를 채팅 메시지에 쓰지 마세요.

회사는 비밀번호와 2단계 인증 비밀키를 휴대전화에서 암호화해 Vault에 저장하며, AI 모델에는 비밀번호를 전달하지 않는다고 설명합니다. 로그인 연결을 끊으면 저장된 비밀번호가 삭제된다고 안내합니다. 특히 인증 앱의 비밀키를 저장하면 Pickle이 로그인 코드를 생성할 수 있으므로, 그 계정에 부여되는 실제 접근 범위를 생각한 뒤 선택하세요. [로그인 저장 안내](https://www.pickle.com/help/connect/save-login)

## 접근 기간과 연결 해제

![피클 앱의 계정·카드 접근 기록 화면](https://www.pickle.com/help-center/screens/privacy-access-log.webp)

*이미지 출처: [Pickle 공식 도움말 ― 접근 기록 보기](https://www.pickle.com/help/privacy/activity), 2026년 11월 2일 확인. 기록에는 접근 시도가 표시되며, 외부 작업의 성공 여부는 별도로 확인해야 합니다.*

약관은 사용자가 앱을 마지막으로 연 뒤 연결 계정·카드에 접근할 수 있는 기간을 기본 최대 30일 또는 사용자가 고른 더 짧은 기간으로 설명합니다. 기간이 끝나면 해당 정보가 필요한 작업은 앱을 다시 열 때까지 기다린다고 합니다. [서비스 약관](https://www.pickle.com/ko/terms-of-service)

공식 도움말은 **나의 피클 → 연결된 앱 및 서비스 또는 연결된 결제 수단 → 암호화 배너 → 접근 기록**의 경로를 안내합니다. 기록을 열면 최근 접근 항목과 원본 내역을 볼 수 있습니다. 이 기록은 계정·카드 접근을 확인하는 자료이며 예약이나 결제가 성공했다는 증거와는 다릅니다. [접근 기록 보기](https://www.pickle.com/help/privacy/activity)

### 연결을 끊은 뒤에도 확인할 것

공식 도움말은 연결을 끊으면 해당 계정의 연결 정보나 저장된 사이트 로그인이 지워지지만, **이미 대화와 기억에 남은 내용은 그대로 남는다**고 설명합니다. 또 Pickle 브라우저에 이미 열린 로그인 상태는 자동으로 끝나지 않을 수 있습니다. 중요한 계정이라면 원래 서비스의 접속·연결 앱 목록도 확인하세요. [연결 해제 도움말](https://www.pickle.com/help/connect/disconnect)

이 매뉴얼의 권장 방법은 시험에 필요한 계정만 연결하고, 사용하지 않는 연결은 끊으며, 정기적으로 접근 기간을 확인하는 것입니다. **비밀번호를 AI가 보지 못하는 것**과 **연결된 계정으로 어떤 행동을 할 수 있는지**는 서로 다른 질문입니다.
