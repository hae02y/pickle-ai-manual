# 10. 요금과 점검표

Pickle의 공식 요금 도움말은 대화와 작업에 요금제가 필요하고, 요금제마다 주간 사용 한도가 있다고 설명합니다. 표시 가격과 한도는 바뀔 수 있으므로 결제 전 앱의 요금제 화면을 기준으로 확인하세요. [요금제 도움말](https://www.pickle.com/help/credits/plans)

## 2026년 11월 2일 확인한 요금제

| 요금제 | 월 표시 가격 | 주간 사용 크레딧 |
| --- | ---: | ---: |
| Plus | $20 | 470 |
| Pro | $50 | 1,170 |
| Max | $100 | 2,330 |
| Ultra | $200 | 4,670 |

위 표는 [공식 요금 도움말](https://www.pickle.com/help/credits/plans)의 확인 당시 표시값입니다. 실제 청구 가격은 앱의 플랜 화면을 확인하세요. 구독 관리·취소는 App Store 또는 Google Play 설정에서 할 수 있다고 안내합니다. 반복 예약 작업은 실행할 때마다 한도에 포함될 수 있고, 한도에 도달하면 실행이 건너뛰어질 수 있습니다. [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled)

## 매주 또는 매월 점검표

| 항목 | 확인 방법 |
| --- | --- |
| 예약 작업 | Scheduled에서 실행 주기와 기록 확인 |
| 기억 | Bubbles에서 틀리거나 민감한 기억 수정·삭제 |
| 연결 계정 | My Pickle → Connections에서 불필요한 연결 해제 |
| 승인 범위 | 반복적으로 허용한 조건과 결제 한도 재검토 |
| 비용 | 요금제 화면과 실제 구독 청구 확인 |
| 작업 결과 | 예약·주문·결제의 외부 기록 대조 |

## 마지막으로 기억할 것

Pickle에게 일을 맡기는 순간, 대화는 외부 행동으로 이어질 수 있습니다. 그러므로 **무엇을 하게 할지**, **어디서 다시 물어야 할지**, **어떤 증거로 끝났다고 볼지**를 함께 정하세요. 제품이 보여 주는 완료 보고와 외부 사이트의 실제 상태를 비교하는 습관이 가장 중요합니다.
