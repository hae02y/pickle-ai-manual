# 10. 사용량과 점검표

**사용량 안내는 시점과 언어에 따라 다릅니다.** 2026년 11월 2일 편집 기록에는 당시 한국어 자료의 무료 이용·일일 한도·한국 시간 새벽 4시 초기화가 남아 있습니다. 그 버전의 고정 사본은 없어 현재 URL에서 재확인할 수 없습니다. 2026년 11월 24일 확인한 [영어 플랜 안내](https://www.pickle.com/help/credits/plans)와 [사용량 안내](https://www.pickle.com/help/credits/usage-credits)는 **플랜별 주간 크레딧과 매주 월요일 오전 4시 미국 태평양 시간 초기화**를 설명합니다. 영어 플랜 안내에 따르면 기존 Pickle Plus는 신규 판매와 갱신이 종료됐습니다. 과거 자료의 수치를 현재 계정에 그대로 적용하지 마세요.

실제 이용 조건은 계정에 보이는 플랜 카드와 결제 화면에서 확인해야 합니다. **플랜 이름·남은 한도·초기화 시각·구독 갱신 조건**을 적어 두세요. 문서 간 차이는 [18장 업데이트 노트](https://wikidocs.net/498492)에 날짜와 함께 정리했습니다. 한국어 서비스 약관 URL은 2026년 11월 24일 현재 **12월 8일 시행 예정**으로 표시되므로 현행 약관으로 단정하지 않습니다.

## 한도는 어떻게 확인하나요?

![이전 안내에 실린 피클 앱의 사용량 카드](https://www.pickle.com/help-center/screens/credits-plans.webp)

*이미지 출처: [Pickle 공식 도움말 ― 요금제 확인하기](https://www.pickle.com/help/credits/plans), 2026년 11월 2일 확인. 이전 지역·버전의 예시 화면일 수 있습니다.*

| 확인 항목 | 이유 |
| --- | --- |
| 현재 플랜과 크레딧 수 | 지역별 무료·유료 조건이 다를 수 있음 |
| 리셋 주기와 시간대 | 일일/주간 안내가 서로 달라 오래된 문서에 의존하면 작업이 중단될 수 있음 |
| 예약 작업·아침 브리핑의 소모 | 사용자가 직접 대화하지 않아도 백그라운드 작업이 실행될 수 있음 |
| 전화 통화 제한 | Pickle이 대신 거는 전화에는 별도 일일 제한이 있다고 영어 안내에 명시됨 |

영어 [사용량 안내](https://www.pickle.com/help/credits/usage-credits)는 아침 브리핑이 기본으로 꺼져 있고, 켜면 크레딧을 쓴다고 합니다. 반면 [영어 제품 소개](https://pickle.com/help/start/what-is-pickle)는 기본으로 보낸다고 하며, [예약 작업 안내](https://www.pickle.com/help/tasks/scheduled)는 같은 페이지 안에서 두 표현을 모두 씁니다. 따라서 기본값을 하나로 확정하지 말고 실제 계정의 **예약한 작업**에서 활성 상태와 실행 기록을 확인하세요. 한도에 도달하면 예약 작업 실행이 건너뛰어질 수 있습니다. 과거 한국어 안내의 **한도 초기화 티켓**은 현재 계정에 표시될 때만 해당합니다.

예를 들어 월요일 아침까지 제출할 보고서가 있다면, 일요일 저녁에 플랜 카드와 예약 작업의 다음 실행 시각을 확인하세요. 한도가 이미 찼거나 브리핑이 꺼져 있다면 월요일 요약이 오지 않을 수 있습니다. 제출 마감 자체는 원래 캘린더에도 남겨 두세요. 전화는 주간 크레딧과 별도의 일일 한도도 확인해야 합니다. [사용량 안내](https://www.pickle.com/help/credits/usage-credits)

| 독자의 질문 | 확인할 화면·기록 | 해석 |
| --- | --- | --- |
| 이번 주에 얼마나 남았나? | 나의 피클의 플랜 카드 | 표시된 사용률과 초기화 시각을 기준으로 판단 |
| 예약 작업이 왜 오지 않았나? | 예약한 작업의 활성 상태·기록, 플랜 카드 | 일시정지·한도 초과·실행 실패를 구분 |
| 전화가 안 되는 이유는? | 사용량 화면과 전화 관련 안내 | 주간 크레딧 외 별도 일일 제한 가능성 확인 |
| 플랜을 바꾸면 얼마인가? | 앱의 실제 결제 화면 | 웹의 달러 가격을 한국 결제액으로 환산해 단정하지 않음 |

## 매주 또는 매월 점검표

| 항목 | 확인 방법 |
| --- | --- |
| 예약 작업 | 피클 프로필의 **예약한 작업**에서 주기와 기록 확인 |
| 기억 | **함께한 추억**에서 틀리거나 민감한 기억 수정·삭제 |
| 연결 계정 | **나의 피클 → 연결**에서 불필요한 연결 해제 |
| 승인 범위 | 반복적으로 허용한 조건과 결제 한도 재검토 |
| 사용량 | 현재 플랜의 주기·크레딧·예약 작업 소모 확인 |
| 작업 결과 | 예약·주문·결제의 외부 기록 대조 |

## 마지막으로 기억할 것

Pickle에게 일을 맡기는 순간, 대화는 외부 행동으로 이어질 수 있습니다. 그러므로 **무엇을 하게 할지**, **어디서 다시 물어야 할지**, **어떤 증거로 끝났다고 볼지**를 함께 정하세요. 제품이 보여 주는 완료 보고와 외부 사이트의 실제 상태를 비교하는 습관이 가장 중요합니다.

## 기술적으로 읽기

크레딧은 모델 호출, 도구 실행, 전화, 백그라운드 작업 같은 **서로 다른 시스템 자원**을 묶어 보여 주는 제품 단위일 수 있습니다. 그러나 Pickle이 어떤 행동에 몇 번의 모델 호출과 얼마의 컴퓨팅 비용을 쓰는지는 공개되지 않았습니다. 따라서 크레딧을 토큰 수나 실제 비용으로 환산하지 않습니다. 예약 작업은 사용자가 앱을 보지 않을 때도 실행될 수 있으므로 [12장](https://wikidocs.net/491191)의 스케줄러 설명과 [15장](https://wikidocs.net/491194)의 접근 기록 점검을 함께 읽으세요.
