# 10. 사용량과 점검표

**공식 자료가 시점·언어별로 다릅니다.** 2026년 11월 2일 확인한 한국어 안내에는 무료·일일 한도·한국 시간 새벽 4시 초기화가 있었습니다. 2026년 11월 17일 [영어 플랜 안내](https://www.pickle.com/help/credits/plans)와 [사용량 안내](https://www.pickle.com/help/credits/usage-credits)는 **유료 플랜과 주간 크레딧**, **월요일 오전 4시 미국 태평양 시간 초기화**를 설명합니다. 현재 계정의 지역·플랜 화면과 최신 약관이 실제 적용 조건입니다.

## 한도는 어떻게 확인하나요?

![피클 앱의 나의 피클 탭과 일일 사용량 카드](https://www.pickle.com/help-center/screens/credits-plans.webp)

*이미지 출처: [Pickle 공식 도움말 ― 요금제 확인하기](https://www.pickle.com/help/credits/plans), 2026년 11월 2일 확인. 이전 지역·버전의 예시 화면일 수 있습니다.*

| 확인 항목 | 이유 |
| --- | --- |
| 현재 플랜과 크레딧 수 | 지역별 무료·유료 조건이 다를 수 있음 |
| 리셋 주기와 시간대 | 일일/주간 안내가 서로 달라 오래된 문서에 의존하면 작업이 중단될 수 있음 |
| 예약 작업·아침 브리핑의 소모 | 사용자가 직접 대화하지 않아도 백그라운드 작업이 실행될 수 있음 |
| 전화 통화 제한 | 크레딧 외에 별도 일일 제한이 있을 수 있음 |

영어 [사용량 안내](https://www.pickle.com/help/credits/usage-credits)는 아침 브리핑이 기본적으로 꺼져 있고 켜면 크레딧을 쓴다고 설명합니다. [영어 제품 소개](https://pickle.com/help/start/what-is-pickle)의 기본 브리핑 표현과도 차이가 있으므로 실제 계정의 설정을 확인해야 합니다. 한도에 도달하면 예약 작업도 실행되지 않을 수 있으므로 중요한 일정은 직접 확인하세요. 예전 한국어 안내의 **한도 초기화 티켓**은 현재 계정에 보일 때만 해당합니다.

## 마지막으로 기억할 것

Pickle에게 일을 맡기는 순간, 대화는 외부 행동으로 이어질 수 있습니다. 그러므로 **무엇을 하게 할지**, **어디서 다시 물어야 할지**, **어떤 증거로 끝났다고 볼지**를 함께 정하세요. 제품이 보여 주는 완료 보고와 외부 사이트의 실제 상태를 비교하는 습관이 가장 중요합니다.

## 기술적으로 읽기

크레딧은 모델 호출, 도구 실행, 전화, 백그라운드 작업 같은 **서로 다른 시스템 자원**을 묶어 보여 주는 제품 단위일 수 있습니다. 그러나 Pickle이 어떤 행동에 몇 번의 모델 호출과 얼마의 컴퓨팅 비용을 쓰는지는 공개되지 않았습니다. 따라서 크레딧을 토큰 수나 실제 비용으로 환산하지 않습니다. 예약 작업은 사용자가 앱을 보지 않을 때도 실행될 수 있으므로 [12장](https://wikidocs.net/491191)의 스케줄러 설명과 [15장](https://wikidocs.net/491194)의 접근 기록 점검을 함께 읽으세요.
