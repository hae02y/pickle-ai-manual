# 10. 사용량과 점검표

Pickle의 [한국어 요금 도움말](https://www.pickle.com/help/credits/plans)은 한국 계정을 무료로 제공하고, 따로 구매하는 유료 요금제가 없다고 설명합니다. 대신 대화와 작업에는 **일일 사용량 한도**가 있으며 한국 시간 새벽 4시에 초기화됩니다. 앱의 안내가 바뀌면 현재 화면을 기준으로 확인하세요.

## 하루 한도는 어떻게 작동하나요?

![피클 앱의 나의 피클 탭과 일일 사용량 카드](https://www.pickle.com/help-center/screens/credits-plans.webp)

*이미지 출처: [Pickle 공식 도움말 ― 요금제 확인하기](https://www.pickle.com/help/credits/plans), 2026년 11월 2일 확인. 화면의 수치는 예시입니다.*

| 한도를 쓰는 것 | 한도를 쓰지 않는 것으로 안내된 것 |
| --- | --- |
| 피클의 답변, 기본 채팅 통화, 사용자가 맡긴 일과 예약 작업 | 피클이 스스로 하는 아침 루틴, 3D 월드 통화 중의 대화 |

나의 피클 탭 맨 위에서 오늘 쓴 비율과 초기화 시각을 볼 수 있습니다. 한도에 도달하면 새 작업을 시작할 수 없고, 사용자가 맡긴 예약 작업은 다음 초기화 전까지 실행을 건너뛸 수 있습니다. 앱의 **한도 초기화 티켓**으로 기다리지 않고 이어서 쓸 수 있다는 안내도 있습니다. 티켓의 구매 여부와 가격은 앱에서 확인하세요. [사용량 도움말](https://www.pickle.com/help/credits/usage-credits), [요금제 도움말](https://www.pickle.com/help/credits/plans)

## 시작 전 점검표

| 항목 | 확인 |
| --- | --- |
| 최신 약관의 이용 지역·연령에 해당한다 | □ |
| 내가 맡길 첫 작업과 완료 조건을 적었다 | □ |
| 결제·예약 확정 전 승인받을 조건을 정했다 | □ |
| 필요한 계정만 연결한다 | □ |
| 비밀번호·카드 번호는 채팅에 쓰지 않는다 | □ |
| 결과를 확인할 외부 사이트나 메시지를 안다 | □ |

## 매주 또는 매월 점검표

| 항목 | 확인 방법 |
| --- | --- |
| 예약 작업 | Scheduled에서 실행 주기와 기록 확인 |
| 기억 | Bubbles에서 틀리거나 민감한 기억 수정·삭제 |
| 연결 계정 | My Pickle → Connections에서 불필요한 연결 해제 |
| 승인 범위 | 반복적으로 허용한 조건과 결제 한도 재검토 |
| 사용량 | 일일 한도와 티켓 사용 내역 확인 |
| 작업 결과 | 예약·주문·결제의 외부 기록 대조 |

## 마지막으로 기억할 것

Pickle에게 일을 맡기는 순간, 대화는 외부 행동으로 이어질 수 있습니다. 그러므로 **무엇을 하게 할지**, **어디서 다시 물어야 할지**, **어떤 증거로 끝났다고 볼지**를 함께 정하세요. 제품이 보여 주는 완료 보고와 외부 사이트의 실제 상태를 비교하는 습관이 가장 중요합니다.
