# 04. 예약과 결제

예약과 결제는 다른 사람과의 약속이나 돈의 이동을 만듭니다. Pickle은 이런 행동 전에 사용자에게 조건과 비용을 보여 주고, 승인한 범위에서 진행한다고 설명합니다. 금액이 결제 직전에 오르면 다시 묻는다고도 안내합니다. [개인정보·보안 안내](https://www.pickle.com/privacy), [서비스 약관](https://www.pickle.com/terms-of-service)

## 예약을 맡기는 순서

| 순서 | 요청 또는 확인 |
| --- | --- |
| 1. 후보 | 장소, 시간, 인원, 예산, 취소 규칙을 비교하게 합니다. |
| 2. 선택 | 어느 후보로 진행할지 직접 고릅니다. |
| 3. 승인 | 확정할 대상·시간·금액·공유 정보를 카드에서 확인합니다. |
| 4. 결과 | 예약 번호와 상대 사이트의 예약 내역을 대조합니다. |
| 5. 보관 | 취소 마감과 연락처를 기록합니다. |

“가격이 올라가도 알아서 해 줘”처럼 범위가 넓은 말은 피하세요. 예산 상한을 정하고 그 밖의 변경은 다시 묻게 하세요. 결제 승인 방식은 결제 수단에 따라 다를 수 있습니다. 약관은 Stripe Link를 연결한 경우 각 결제를 Link에서 승인한다고 설명합니다. 실제 화면에서 무엇을 승인하는지 확인하세요. [서비스 약관](https://www.pickle.com/terms-of-service)

## 카드 정보를 입력할 때

카드 번호와 비밀번호를 채팅 문장에 적지 마세요. Pickle은 보안 카드와 Vault를 통해 값을 받으며, AI 모델에는 카드 번호와 비밀번호를 전달하지 않는다고 설명합니다. 이는 회사의 공개 설명이며 이 매뉴얼이 독립 검증한 결과는 아닙니다. [개인정보·보안 안내](https://www.pickle.com/privacy), [로그인 저장 안내](https://www.pickle.com/help/connect/save-login)

## 실패했을 때

결제 화면이 멈추거나 “확인 중”이라고 보여도 주문이 실제로 접수됐을 수 있습니다. 같은 작업을 다시 시키기 전에 카드 내역과 업체 주문·예약 내역을 확인하세요. 중복이 있으면 해당 업체의 취소·환불 절차를 밟아야 합니다. Pickle 약관은 외부 서비스에서 끝난 행동을 Pickle의 중단 명령만으로 되돌릴 수 없다고 밝힙니다. [서비스 약관](https://www.pickle.com/terms-of-service)

## 예시 요청

> “토요일 오후 7시, 2명 식당을 찾아줘. 1인당 예산은 5만 원 이내야. 예약금과 취소 수수료가 있는지 표시해 줘. 내 승인을 받기 전에는 예약 확정이나 결제를 하지 마.”
