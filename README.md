# 처음 쓰는 피클 AI: 개인 에이전트 사용 매뉴얼

Pickle.com의 개인 AI 에이전트 **Pickle**을 처음 접하는 사람을 위한 비공식 한국어 안내서입니다. 대화만 하는 AI를 넘어, 웹사이트에서 예약·주문을 진행하거나 전화를 걸고, 사용자가 연결한 계정의 정보를 읽는 기능을 어떻게 이해하고 점검할지 설명합니다.

> **확인 기준: 2026년 11월 2일.** 이 문서는 [Pickle 공식 도움말](https://www.pickle.com/help), [개인정보 안내](https://www.pickle.com/privacy), [서비스 약관](https://www.pickle.com/terms-of-service)을 바탕으로 썼습니다. 저자는 제품을 직접 사용해 모든 화면·작업 성공률을 검증하지 않았습니다. 화면 이름, 요금, 제공 지역은 바뀔 수 있습니다.

## 먼저 알아둘 점

| 질문 | 2026년 11월 2일 확인 내용 |
| --- | --- |
| 어떤 제품인가요? | `pickle.com`의 개인 AI 에이전트입니다. 동명인 PickleAI 데스크톱 앱이나 회의 아바타 서비스와 다릅니다. |
| 누가 사용할 수 있나요? | 공식 약관은 미국에 있는 만 18세 이상을 대상으로 명시합니다. 한국에서의 이용 가능성을 이 매뉴얼이 보증하지 않습니다. |
| 무엇을 할 수 있나요? | 대화·음성 통화, 기억 관리, 웹 작업, 전화, 연결 계정 활용 등을 회사가 안내합니다. |
| 바로 결제하나요? | 회사는 결제·예약 같은 중요한 단계에서 사용자가 조건을 확인하도록 설계했다고 설명합니다. 실제 조건은 승인 카드에서 확인하세요. |
| 공식 매뉴얼인가요? | 아닙니다. 실제 계정 설정과 최신 기능은 Pickle의 공식 안내가 우선합니다. |

## 이 매뉴얼의 사용법

각 장의 **제품 설명**은 공식 자료에 링크를 붙였습니다. **권장 방법**은 독자가 실수와 불필요한 권한을 줄이도록 이 매뉴얼에서 제안하는 절차입니다. 둘을 구분해서 읽어 주세요.

서비스를 실제로 사용하기 전에는 [공식 도움말](https://www.pickle.com/help)과 [약관](https://www.pickle.com/terms-of-service)을 다시 확인하세요. 특히 한국 독자라면 제공 지역부터 확인해야 합니다.
