Pickle.com의 개인 AI 에이전트 **Pickle**을 처음 접하는 사람을 위한 비공식 한국어 안내서입니다. 웹·전화 작업의 사용법과 함께, AI 에이전트의 작동 원리, Vault 암호화, OAuth 토큰, 접근 로그의 신뢰 경계를 **공개 소스와 공식 문서**로 분석합니다.

## 읽는 순서

1. [시작 전 확인](https://wikidocs.net/471753): 이용 자격, 계정, 사용량, 처음 맡길 일
2. [대화와 음성 통화](https://wikidocs.net/471754): 요청을 분명하게 말하고 결과를 읽기
3. [작업 위임](https://wikidocs.net/471755): 웹 작업·전화·승인 카드·완료 확인
4. [예약과 결제](https://wikidocs.net/471756): 돈과 약속이 걸린 작업의 경계
5. [연결 계정과 Vault](https://wikidocs.net/471757): 로그인, 카드, 접근 권한
6. [기억과 예약 작업](https://wikidocs.net/471758): 기억 수정, 반복 실행 관리
7. [개인정보와 공유](https://wikidocs.net/471759): 누가 무엇을 볼 수 있는지
8. [오류·중단·복구](https://wikidocs.net/471760): 실패 후 재시도와 외부 상태 확인
9. [실전 요청 예시](https://wikidocs.net/471761): 부담이 작은 일부터 시작하는 문장
10. [사용량과 점검표](https://wikidocs.net/471762): 지역·플랜별 한도와 정기 점검

**기술 심화:** [11장 시스템 구조](https://wikidocs.net/491190) → [12장 AI 기술](https://wikidocs.net/491191) → [13장 Vault와 enclave](https://wikidocs.net/491192) → [14장 OAuth](https://wikidocs.net/491193) → [15장 접근 로그](https://wikidocs.net/491194) → [16장 위협 모델·검증](https://wikidocs.net/491195). 각 장의 위키독스 주소로 바로 이동할 수 있습니다.

**따라 하기:** [17장 ― 피클 AI에 첫 작업 맡기기](https://wikidocs.net/493290)에서는 후보 검색에서 문의·예약으로 넘어가는 과정을 요청문, 승인 조건, 완료 증거와 함께 연습합니다. 실제 예약 성공 사례가 아니라 공식 기능을 바탕으로 구성한 예시입니다.

**최신 안내:** [18장 업데이트 노트](https://wikidocs.net/498492)는 시점·언어가 다른 공식 문서와 미래 시행 약관을 구분합니다. 제품 변화가 확인되면 확인일과 영향을 받는 본문을 이 장에 추가합니다.

**저자를 위한 부록:** [19장 출판과 수익화](https://wikidocs.net/498493)는 이 매뉴얼을 전자책·POD·교육 자료로 발전시키는 방법과 위키독스의 광고·후원·판매 선택지를 비교합니다. 피클 제품의 제휴 프로그램이나 실제 수익을 주장하지 않습니다.

## 이 매뉴얼의 사용법

각 장의 **제품 설명**은 공식 자료에 링크를 붙였습니다. **권장 방법**은 독자가 실수와 불필요한 권한을 줄이도록 이 매뉴얼에서 제안하는 절차입니다. 기술 심화 장은 **공식 확인 사실·공개 소스의 정적 분석·구현 기반 추론·미확인 사항**을 구분합니다. 둘을 섞어 읽지 마세요.

기존 본문 화면 이미지는 Pickle 공식 도움말의 원본 URL을 사용하며, 기술 도식은 이 저장소에서 새로 작성했습니다. 실제 앱 화면은 업데이트에 따라 달라질 수 있습니다.

8장의 복구 흐름과 19장의 콘텐츠 활용 경로도 자체 도식으로 추가했습니다. 그림은 설명을 위한 판단 모델이며 제품 내부 화면이나 수익 예측 그래프가 아닙니다.

서비스를 실제로 사용하기 전에는 [공식 도움말](https://www.pickle.com/help)과 가입 화면에 제시되는 **현행 지역 약관**을 확인하세요. 현재 [한국어 약관 페이지](https://www.pickle.com/ko/terms-of-service)는 12월 8일 시행 예정 문서입니다. 앱에서 실제 제공 지역과 계정 조건도 확인해야 합니다.
